# Hi, I'm Wu Songyuan

I work on FPGA and embedded systems, with an emphasis on signal processing, hardware/software co-design, and reproducible development workflows.

My current projects cover **FPGA signal processing**, **Zynq PS + PL systems**, **STM32 dual-core development**, and **ESP32-S3 connected devices**. Most repositories include build scripts, simulation or self-test entry points, and practical hardware documentation.

我主要从事 FPGA 与嵌入式系统开发，关注信号处理、软硬件协同设计和可复现的开发流程。目前的项目涵盖 **FPGA 信号处理**、**Zynq PS + PL 系统**、**STM32 双核开发**和 **ESP32-S3 联网设备**，大多数仓库都提供构建脚本、仿真或自测入口，以及必要的硬件说明。
